# ⚔️ Travian Klasik — Offline

Tiruan Travian Classic yang berjalan 100% offline di browser, tanpa internet, tanpa server.

## Cara main

**Klik dua kali `index.html`** — selesai. Game terbuka di browser dan tersimpan otomatis
di browser tersebut (localStorage). Gunakan browser yang sama agar kemajuanmu tetap ada.

## Fitur

- **3 suku klasik**: Romawi, Teuton, Galia — lengkap dengan 9 unit asli per suku
  (Legioner, Pemukul Gada, Phalanx, pengintai, kavaleri, pendobrak, katapel, pemukim)
  beserta statistik serang/bertahan/kecepatan/daya angkut dari Travian asli.
- **18 ladang sumber daya** (4 kayu, 4 tanah liat, 4 besi, 6 gandum) + pusat desa dengan
  17 jenis bangunan: Gedung Utama, Gudang, Lumbung, Barak, Istal, Bengkel Perang, Akademi,
  Pandai Besi, Pasar, Kediaman, Persembunyian, tembok per suku, dll.
- **170 bot aktif** di peta 61×61 yang **terus membesar seperti pemain asli** — penduduk
  bertambah, pasukan dilatih ulang, tembok dibangun, dan sesekali mereka merampok desamu
  (frekuensi & kekuatan rendah di tingkat Mudah).
- **Pertempuran formula Travian**: serangan vs rampokan, bonus tembok, pandai besi,
  pendobrak merobohkan tembok, katapel menghancurkan bangunan, pengintaian, laporan
  pertempuran lengkap.
- **Ekspansi**: Kediaman tk.10 → 3 Pemukim → dirikan desa baru di petak kosong.
- **Simulasi offline**: tutup game kapan saja — saat dibuka lagi, produksi, antrian,
  pertempuran, dan pertumbuhan bot disusulkan (maks. 7 hari).
- **Statistik peringkat** semua pemain & bot, ekspor/impor save, kecepatan server 1x–100x.
- **Mobile-first**: nyaman dimainkan di layar ponsel maupun desktop.

## Tips awal

1. Naikkan ladang sumber daya dulu (terutama 1 dari tiap jenis ke tk.2–3).
2. Bangun Titik Kumpul → Barak → latih pasukan dasar.
3. Rampok bot kecil terdekat lewat Peta (klik desa → 💰 Rampok) — jarahan mempercepat segalanya.
4. Bangun Persembunyian & tembok sebelum pendudukmu lewat 80 (perlindungan pemula berakhir).
